# Developer Manual

This document is intended for future developers who need to install, run, and extend this application.

## 1) Install

### Requirements
- Node 18 or newer

### Install steps
1. Clone the repo
2. Run `npm install`

## 2) Supabase setup

Create a Supabase project and make a table named `favorites`.

SQL:

```sql
create table favorites (
  id bigint generated by default as identity primary key,
  title text not null,
  competition text,
  match_url text,
  created_at timestamptz default now()
);
