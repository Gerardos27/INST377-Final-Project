What this app does

Our goal in creating this app was to give soccer fans instant access to highlight data from Scorebat, delivering high-quality match videos in one place so users never miss a key moment or game.

Users can save a match as a favorite and the app stores it in Supabase.

Tech used

  • Node and Express for the server
  • Supabase for the database
  • Chart.js for a chart
  • Swiper for a slider
